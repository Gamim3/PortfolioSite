THE PROCESS

This project was an exploration into translating the 2D concept art from Persona 3 into a fully realized 3D asset ready for a game engine.

The biggest challenge was the hair topology. I needed to ensure the silhouette remained sharp from all angles while keeping the polycount reasonable for real-time rendering.
